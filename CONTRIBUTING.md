# Contributing

Issues and pull requests are welcome.

1. Fork and clone the repository.
2. Create a focused branch.
3. Run `python -m unittest discover -s tests -v` and
   `python scripts/check_frontend.py`.
4. Keep the standalone project dependency-free unless a dependency provides a clear,
   documented benefit.
5. Include screenshots for visible interface changes.

Please avoid committing real household notes, private IP addresses, Home
Assistant tokens, or other personal configuration.
